=====================================================================
MARSAR — STEP-BY-STEP RUN COMMANDS (backend + frontend)
=====================================================================
Two folders, typically TWO terminals:
  - backend/   -> offline pipeline (bootstrap_and_run.py) + FastAPI API
  - frontend/  -> Next.js UI

Fill SQLite first with bootstrap_and_run.py (or run_offline_pipeline.py),
then start uvicorn, then npm run dev. The UI is a client of the API on
port 8000. Database file: backend/marsar_offline.db

Optional: python run_worker.py watches backend/data/ for new CSV/JSON/XML
files. It is not required for the default offline demo.

See also the repo-root commands.txt (Windows PowerShell + Linux bash).


---------------------------------------------------------------
PART A — BACKEND
---------------------------------------------------------------
Terminal 1: pipeline + API. Terminal 2 (optional): folder watcher.

STEP 1. Unzip this project over your existing folder (skip if already done)
    cd backend

STEP 2. Create a virtual environment (skip if you already have one)
    python3 -m venv venv

STEP 3. Activate the virtual environment
    # Windows (cmd):        venv\Scripts\activate
    # Windows (PowerShell):  venv\Scripts\Activate.ps1
    # macOS / Linux:         source venv/bin/activate

STEP 4. Install dependencies
    pip install -r requirements.txt

STEP 5. Fill the local database (required for alerts/graph/reports)
    python bootstrap_and_run.py
    python bootstrap_and_run.py --wipe-db
    python run_offline_pipeline.py --input data/bitcoin_telemetry.csv

STEP 6. Start the FastAPI server (keep this running)
    python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload

STEP 7. (Optional) Watch backend/data/ for new CSV/JSON/XML files
    python run_worker.py

STEP 8. Verify the API is up
    curl http://127.0.0.1:8000/health
    Expected: JSON with "status": "healthy" and record_counts.

STEP 9. Inspect alerts
    curl "http://127.0.0.1:8000/api/v1/alerts/ranked?limit=5"

STEP 10. Tests
    python -m pytest tests -q
    Expect 17 passed.

STEP 11. Train the backend ML model (optional)
    python train_elliptic_xgboost.py
    python train_elliptic_xgboost.py --synthetic
    Restart uvicorn after training so weights reload.

STEP 12. Stop
    Ctrl+C, then deactivate


---------------------------------------------------------------
PART B — FRONTEND (Next.js)
---------------------------------------------------------------
Requires Node.js 18+ (node -v). Keep the backend API running.

STEP 1.
    cd frontend

STEP 2. Install dependencies
    npm install

STEP 3. (Optional) point it at a different backend URL
    Copy frontend/.env.local.example to .env.local and set:
    MARSAR_API_URL=http://127.0.0.1:8000

STEP 4. Start the dev server
    npm run dev

STEP 5. Open it in a browser
    http://localhost:3000
    Use Overview, Alerts, Visualizer, Tracer, Reports.

STEP 6. Reports
    Paste a txid from Alerts or Transactions (for example tx_ransom_peel_...).
    Generate STR uses POST /api/v1/export-str against marsar_offline.db.

STEP 7. To stop
    Ctrl+C in the frontend terminal.

---------------------------------------------------------------
TROUBLESHOOTING
---------------------------------------------------------------
- "ModuleNotFoundError: No module named 'app'"
    -> Run python/uvicorn from the backend folder with the venv active.

- "AttributeError: 'Settings' object has no attribute ..."
    -> Stale backend copy; use this repo's backend/app/core/config.py.

- "Engine 5 ML model not found" / invalid joblib
    -> Train from backend (not frontend):
           python train_elliptic_xgboost.py
       or without Elliptic CSVs:
           python train_elliptic_xgboost.py --synthetic
       Weights: app/ml/weights/bitcoin_network_gbdt.joblib
       Schema: 13 features in app/ml/feature_extractor.py.
       If the file is missing or fails the contract, inference uses a
       small embedded fallback so alerts still generate.

- "ModuleNotFoundError: No module named 'pydantic_core._pydantic_core'"
    -> Recreate venv with Python 3.11 or 3.12, then pip install -r requirements.txt

- Frontend empty / cannot reach backend
    -> Keep uvicorn running on port 8000.
    -> If you changed the API port, set MARSAR_API_URL in frontend/.env.local.

- Port 8000 already in use
    -> python -m uvicorn app.main:app --host 127.0.0.1 --port 8001 --reload
       and set MARSAR_API_URL=http://127.0.0.1:8001
