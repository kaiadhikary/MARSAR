================================================================================
MARSAR — FULL-STACK RUN GUIDE (BACKEND + FRONTEND IN SYNC)
================================================================================

START ORDER (important)
-----------------------
  1. Backend FIRST  — FastAPI on port 8000 (data + API)
  2. Frontend SECOND — Next.js on port 3000 (proxies /api/v1 and /health to backend)

The dashboard will show empty states or "backend unreachable" if you open the
frontend before the API is running. Always boot the backend, confirm /health,
then start the frontend.


================================================================================
ONE-TIME SETUP
================================================================================

BACKEND (run from this folder: backend/)
----------------------------------------
  python -m pip install -r requirements.txt

FRONTEND (run from: frontend/)
------------------------------
  npm install
  copy .env.local.example .env.local        # Windows
  # cp .env.local.example .env.local        # Linux / macOS

  .env.local must point at the backend:
    MARSAR_API_URL=http://127.0.0.1:8000


================================================================================
EVERY SESSION — STEP BY STEP
================================================================================

STEP 1 — Bootstrap data (backend terminal, first run or after a wipe)
---------------------------------------------------------------------
  cd backend
  python bootstrap_and_run.py

  This creates/updates marsar_offline.db, loads GeoIP, trains/validates the ML
  model if needed, ingests data/bitcoin_telemetry.csv, clusters entities, and
  generates ranked alerts. Safe to re-run; it does not wipe data unless you pass
  --wipe-db.

  Optional flags:
    python bootstrap_and_run.py --input path/to/your_file.csv
    python bootstrap_and_run.py --wipe-db          # destructive: clears DB first


STEP 2 — Start the backend API (keep this terminal open)
--------------------------------------------------------
  cd backend
  python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload

  Verify before moving on:
    curl http://127.0.0.1:8000/health

  Expected: status "healthy" with non-zero transaction/alert counts after bootstrap.


STEP 3 — Start the frontend (second terminal, only after step 2 is healthy)
---------------------------------------------------------------------------
  cd frontend
  npm run dev

  Open:  http://localhost:3000
  API docs (backend direct):  http://127.0.0.1:8000/docs
  Built-in HTML dashboard:    http://127.0.0.1:8000/dashboard


================================================================================
HOW THE TWO SERVICES STAY IN SYNC
================================================================================

  Browser  -->  Next.js :3000  -->  rewrites /api/v1/* and /health  -->  FastAPI :8000

  - Upload a dataset in the UI (/dataset): ingest + pipeline run happen on the backend.
  - Alerts, graph, tracer, and reports all read from the same SQLite DB the backend owns.
  - If the UI looks empty, check /health on port 8000 first, then re-run bootstrap.


================================================================================
QUICK HEALTH CHECKS (backend must be running)
================================================================================

  curl http://127.0.0.1:8000/health
  curl "http://127.0.0.1:8000/api/v1/alerts/ranked?limit=5"
  curl "http://127.0.0.1:8000/api/v1/graph/topology?limit_tx=10"
  curl "http://127.0.0.1:8000/api/v1/compliance/flagged?limit=5"


================================================================================
COMMON BACKEND-ONLY TASKS
================================================================================

Run pipeline on a specific file (without the full bootstrap):
  python run_offline_pipeline.py --input data/bitcoin_telemetry.csv

Re-generate alerts after manual ingest via API:
  curl -X POST http://127.0.0.1:8000/api/v1/pipeline/run

Watch data/ for new CSV/JSON/XML drops (optional background worker):
  python run_worker.py

Generate STR dossier from CLI (no HTTP):
  python generate_html_report.py <txid>

Run tests:
  python -m pytest tests/ -v

Inspect local database:
  python check_db.py
  python check_clusters.py
  python check_transactions.py

Re-train ML weights:
  python train_elliptic_xgboost.py

Purge all forensic data (clean slate):
  curl -X POST http://127.0.0.1:8000/api/v1/system/reset
  python bootstrap_and_run.py


================================================================================
TROUBLESHOOTING
================================================================================

  UI says "backend unreachable"
    -> Start uvicorn on port 8000 before npm run dev.
    -> Confirm frontend/.env.local has MARSAR_API_URL=http://127.0.0.1:8000

  /health shows 0 transactions
    -> Run: python bootstrap_and_run.py

  Uploaded a file but no new alerts
    -> Dataset page triggers pipeline automatically; or POST /api/v1/pipeline/run

  Port 8000 already in use
    -> Stop the other process or change the port in both uvicorn and .env.local

  Auth errors (401) on API calls
    -> Default is no auth. If you enabled MARSAR_REQUIRE_AUTH=true in backend/.env,
       either set it back to false for local dev or add a login flow to the UI.
