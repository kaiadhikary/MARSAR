Easiest way

First make sure your venv is active:

cd D:\marsar\backend
.\venv\Scripts\Activate.ps1

Then run:

python cluster_explorer.py

You'll get:

1) Top 10 recent transactions -> cluster addresses
2) All suspicious transactions -> cluster addresses
0) Exit
Choose 1

It will show something like:

[1] TX abc123...
    Risk score : 15.0/100
    CoinJoin?  : yes
    Blacklist? : no
    Flags      : ...

The explorer already prints Risk score : XX/100 for each transaction.

To see ONLY suspicious ones

Run:

python cluster_explorer.py --mode suspicious --min-score 30

For high-risk only:

python cluster_explorer.py --mode suspicious --min-score 70

Those thresholds are already built into your explorer.
